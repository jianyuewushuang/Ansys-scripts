## 1. 任务目标与最终结果

### 1.1 目标

按 Ansys 官方文档配置 Fluent MCP，并对 `data/1.stl` 做外部空气动力学仿真：
使用飞机仿真常用参数、精度要求不高、产出仿真结果与**丰富的可视化后处理图像**。

### 1.2 最终结果

| 攻角 | C_L | C_D | L/D | 升力 L [N] | 阻力 D [N] |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0° | 0.0218 | 0.0733 | 0.30 | 1 887 | 6 349 |
| 4° | 0.3408 | 0.0897 | 3.80 | 29 509 | 7 769 |
| 8° | 0.6487 | 0.1315 | **4.93** | 56 161 | 11 384 |
| 12° | 0.8836 | 0.2039 | 4.33 | 76 497 | 17 651 |

（力的绝对值为 `results/forces.json` 中 `L_N` / `D_N`；换算基准 `q·S_ref = 86 573 N`）

**关键判据**

- **升力线斜率**：0.0718 /deg = **4.11 /rad**（0→12° 平均；0→4° 段为 4.58 /rad）。
  展弦比 8.56 的理论值（Prandtl 修正）为 `2π·AR/(AR+2) = 5.09 /rad` → 实测达到理论的 **81~90%**，趋势可信。
- **最大升阻比** 4.93 @ 8°，符合"低精度粗网格"预期区间。
- **对称性**：侧向力 |F_y| < 0.5% 升力（对称外形应 ≈ 0）。
- **压力自洽**：域内平均压力 54 025 Pa vs 远场静压 54 019.9 Pa（偏差 0.01%）。

### 1.3 一句话结论

几何、网格、求解、后处理整条链路全部跑通并产出 38 张图；**C_D 因无边界层棱柱（y+ ≈ 940）被高估约 2–3 倍，应视为上限值**，C_L / 升力线斜率 / 压力场 / 涡系则基本可信。

## 6. 求解设置与关键陷阱

脚本：`scripts/03_solve/final_solve.py`（`MSH / AOAS / WARM / ITERS / NPROC / DELZONE / CASE_FMT / PRELAX / MRELAX` 全走环境变量）。

### 6.1 物理设置

| 项 | 设置 |
| --- | --- |
| 求解器 | 压力基、**Coupled** |
| 湍流 | **k-ω SST**（steady RANS） |
| 材料 | air，**ideal-gas**，μ = 1.628×10⁻⁵ Pa·s（Sutherland 关） |
| 能量方程 | 开 |
| 远场 | `pressure-far-field`：p = 54 019.89 Pa（gauge）、Ma = 0.1872、T = 255.65 K、湍流强度 1%、湍流粘度比 10 |
| 操作压力 | **0**（故 gauge = absolute） |
| 参考值 | S = 65.3375 m²、L(MAC) = 4.1996 m、ρ = 0.73612、V = 60、μ、T、p |
| 来流 | 5 km ISA：T = 255.65 K、p = 54 019.9 Pa、ρ = 0.73612 kg/m³、a = 320.53 m/s、q = 1 325.0 Pa、Re(MAC) = 1.14×10⁷ |
| 离散 | 前 100 步一阶（压力 standard）→ 之后二阶（压力 second-order） |
| 迭代 | 预热 100 + 主迭代 300，每 50 步打印 C_L / C_D |

### 6.2 🔴 三个致命陷阱（都是"静默失败"）

**① 机体内腔必须删除**

布尔后机体内部被当作流体求解 → 出现
`absolute pressure limited to 1.000000e+00 in 182960 cells on zone 230789`，
连续性残差停在 ~1.4×10² 不降，力系数全是垃圾（负阻力、C_L 非单调、|F_y| ≈ 10 kN）。

```python
# ❌ 报 OK 但不生效（zone_names 是未知关键字，被静默忽略）
st.mesh.modify_zones.delete_cell_zone(zone_names=["aircraft"])
# ✅ 正确签名 —— 删除后壁面 shadow 自动消失，力分区变干净
st.mesh.modify_zones.delete_cell_zone(cell_zones=["aircraft"])
```

**② 模型/材料必须用赋值，不能用 `.update()`**

```python
# ❌ .update() 不存在 → 静默 FAIL → 没有湍流模型、材料没设
st.setup.models.viscous.update({...})
# ✅
st.setup.models.viscous = {"model": "k-omega", "k_omega_model": "sst"}
st.setup.materials.fluid["air"] = {"density": {"option": "ideal-gas"}, ...}
```

**③ 🔑 低马赫可压外流场发散的真因：耦合求解器显式松弛过激**

默认显式松弛 0.75 → 本算例（Ma 0.187 + ideal-gas + pressure-far-field）发散：
域内平均压力漂到 ~60 kPa（远高于远场 54 kPa），局部 Ma 冲到 **1.17**，
阻力为负、|F_y| ≈ 10 kN。

```python
pc = st.solution.controls.p_v_controls
pc.explicit_pressure_under_relaxation  = 0.4   # 默认 0.75
pc.explicit_momentum_under_relaxation  = 0.5   # 默认 0.75
```

修正后：**壁面平均压力 54 025 Pa（目标 54 019.9）**，|F_y| ≈ 34 N ≈ 0，阻力转正。

> 附：`p_v_controls.flow_courant_number` 的 `is_active = False`，改不了；
> TUI `solve/set/p-v-controls <n>` 报 "not within limits [0 to 1]"。别在这浪费时间。

### 6.3 力与力矩取值

- 力分区只取 **`aircraft-fluid_box` 单侧**（删区后 shadow 已不存在；两侧一起取会互相污染）。
- 风轴分解：阻力向量 `(cos α, 0, sin α)`，升力向量 `(−sin α, 0, cos α)`。
- 系数：`C = F / (q · S_ref)`，`q·S_ref = 86 572 N`。
- 力矩：`rd.moment` 在本次设置下未能创建（`C_M` 记为 null），报告表中留空。

### 9.3 ANSYS Prime Mesh：**棱柱真的做出来了**

本机已装 `v261/meshing/Prime`；`pip install ansys-meshing-prime` 装 PyPrimeMesh 0.10.4。

```bash
ONLY=mesh SCOPE=all MAXS=2.5 MINS=0.45 BODY=0.9 \
NL=6 H0=0.0005 RATE=1.35 ./.venv/Scripts/python.exe scripts/02_mesh/prime_mesh.py
```

| 指标 | 值 |
| --- | --- |
| 总单元 | 985 824 |
| 流体区 / 机体内腔 | 512 254 / 473 570 |
| 棱柱 | 6 层，首层 0.5 mm，rate 1.35（机体两侧各一套） |
| **y+ 中位数** | **110**（对比无棱柱的 939）✅ |

**Prime 的关键 API 要点**

- `Part.compute_closed_volumes()` → 2 个体；**被两个体共用的 zonelet 就是机体壳**（盒子只属于流体体）。
- 棱柱作用域：**只有 `evaluation_type=ZONES + zone_expression="*"` 能真正解析**。
  按 label、按 zonelet id、加 `part_expression` 三种写法全部解析成**空范围 → 一个棱柱都不长**。
- 导出前必须 `VolumeControlParams(cell_zonelet_type=FLUID)`，
  否则 Fluent 里 cell zone 是 solid，而 `set_zone_type` 拒绝转换（"Values contain disallowed entries"）。
- 导出后两个体叫 `model` / `model.1`：**`model` = 流体区，`model.1` = 机体内腔**；
  用 `delete_cell_zone(cell_zones=['model.1'])` 删内腔，剩余机体壁面为 `wall.model.model.1-shadow`（双面壁的流体侧）。

### 9.4 但它发散了

网格质量检查（`st.mesh.quality()`）：

```
Minimum Orthogonal Quality = 3.666e-04   ← 位于机尾 (23.0, 2.02, 0.79)
Maximum Aspect Ratio       = 2.573e+04   ← 位于远场角落 (75.9, 24.7, 20.0)
```

- 最大长宽比来自**远场盒子上的棱柱**（0.5 mm 首层 + 8 m 面）——正是因为 scope 只能用 `"*"` 无法排除盒子。
- 最小正交质量 3.7×10⁻⁴ 位于机体本身，同样致命。

求解表现：

| 显式松弛 (p / m) | 结果 |
| --- | --- |
| 0.40 / 0.50 | 直接发散，C_D 冲到 **1×10¹⁴⁰** |
| 0.20 / 0.30 | 残差明显好转（连续性 0.56、速度 1×10⁻³），但 **C_L = −14.0、C_D = 319.8**，物理上不成立 |

**结论**：棱柱路径在本工具链下"能做出来但算不稳"。因此最终交付仍采用无棱柱的 v1 结果。

## 12. 已知限制与后续建议

### 12.1 限制

| 项 | 现状 | 影响 |
| --- | --- | --- |
| **近壁分辨率** | y+ 中位数 940，无边界层棱柱 | **C_D 高估约 2.5–3 倍**（应作上限值）；C_L、升力线斜率、压力场受影响小得多 |
| 连续性残差 | 平台在 O(1–10)，未降到机器精度 | 但载荷在最后 150 步稳定 <1%，且压力/对称性自洽 → 力结果可用 |
| 力矩 | `rd.moment` 未能创建 | 报告表中 `C_M` 空缺，俯仰力矩/静稳定裕度未给出 |
| 网格规模 | 318 k 流体单元 | 远场与尾迹分辨率有限，尾涡衰减偏快 |
| 几何 | 体素重建引入阶梯（0.06 m） | 细微外形特征被平滑，可能额外增加压差阻力 |
| C_M 缺失 | — | 无法评估纵向静稳定性 |

### 12.2 后续建议（按性价比排序）

1. **攻"棱柱只作用于机体"**（唯一还堵着的点）
   把盒子与机体拆成两个 part 再给 Prime 设 `part_expression`，
   或在 Prime 里给远场 zonelet 单独设一个"0 层"棱柱控制。
   通了即可同时拿到 y+≈110 与合理网格质量，C_D 有望从 0.073 降到 ~0.03。

2. **用 Fluent GUI 手动加棱柱**，再把 `.msh` 交回脚本批量求解 —— 绕开脚本 API 的惰性 bug。

3. **补俯仰力矩**：修正 `rd.moment` 的参数（或改用 TUI `/report/forces/moment`），
   得到 C_M–α 与静稳定裕度，这才是无人机真正关心的量。

4. **加密尾迹 / 扩大域**：若关注尾涡演化与诱导阻力，把下游从 60 m 拉到 100 m 并加流向加密。

5. **非定常 / 大攻角**：12° 已有明显分离，稳态 RANS 可信度下降；可改 URANS 或转入 α 更密的扫描定位失速点。
